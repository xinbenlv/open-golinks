# 编辑页操作层级

## 问题描述

Go 曾作为独立全宽按钮插在编辑页标题与表单之间，用户反馈位置奇怪，容易误认为提交操作。

## 原因

跳转按钮没有与短链标识放在一起；访问、编辑保存和二维码设置同时争夺注意力。

## 解决方案

短链作为标题，Go 和复制紧邻标题；目标、描述、标签和访问开关直接展示，二维码使用紧凑侧栏，统计直接展示。只有详细历史、转移和删除收起。手机上顺序排列核心区域。

## 相关代码

- `src/web/pages/Edit.tsx:254-453`

## 布局调整不等于更换主题

用户明确要求保留项目的颜色 theming 和字体。此前将 Apple 风格解读为浅色、蓝色和系统字体，超出了布局需求；已移除局部 token 覆盖和硬编码颜色，复用原有主题及排版。界面文案只保留字段、动作和必要的权限与后果说明。

## 折叠不等于极简

用户指出将 Options、二维码、统计全部折叠只是隐藏复杂度。布局应使用空间分配和视觉权重区分主次，让常用内容无需点击即可查看与操作；折叠仅用于低频管理。
